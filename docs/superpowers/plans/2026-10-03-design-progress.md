## Решения по ходу

- Наезд блоков в ряду бэк отклоняет 400 — фронт таких раскладок не строит.
- Пустой шрифт заголовков = «Строгий» (Manrope): старые вишлисты не меняют вид.
- `liveTimer = false` — таймер без секунд, а не «без таймера».
- Голоса старых опросов: индекс → id строкой; фронт выдаёт старым вариантам
  id = индекс. Иначе голоса бы потерялись.
- Варианты голосования правятся в инспекторе, а не прямо на холсте.
- Б8: размытое превью — CSS-переход при загрузке, HEIC переводит браузер,
  обрезка — canvas на клиенте. Настоящего LQIP до загрузки нет: картинки везде
  хранятся строкой URL, и превью потребовало бы менять все схемы.
- Шрифты заголовков — ссылкой на Google Fonts, не `next/font`: Turbopack не
  собирает `next/font` для Playfair Display.
- «Подарено» блокирует бронь; свёртка списка — после 8 карточек / 6 строк / 9 плиток.
- Одинокий узкий блок v2 становится «узким блоком во всю строку».

## Важно перед выкладкой

**Бэк выкладывать раньше фронта.** Новый фронт сохраняет блоки объектом
`{ blocks, rows }` — старый бэк ждёт массив и отклонит сохранение. Новый бэк
принимает оба формата, так что старый фронт с ним работает.

## Локальная среда

`node_modules` в OneDrive частично «только в облаке» (например, иконки
lucide), и Turbopack на них падает. Для просмотра поднималась копия рабочего
дерева вне OneDrive (`%TEMP%\w\web`, `pnpm install --prefer-offline`).
Короткий путь важен: в длинном Turbopack упирается в лимит длины пути Windows.

## Не сделано / отложено

- Варианты голосования перетаскиванием прямо на холсте (сейчас — в инспекторе).
- Режим секрета «ничего» в предпросмотре показывает замок, а не прячет блок.
- Production build на Linux/Docker не прогонялся.
- Финальное ревью — самопроверка автора, без отдельного ревьюера.
