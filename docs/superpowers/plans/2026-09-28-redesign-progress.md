## Блокеры API — сняты 29 сентября

Оба исправлены в бэкенде, коммит `4d9f8bb`.

1. CORS `AllowHeaders` теперь включает `If-Match` — браузер перестал резать заголовок на preflight.
2. `repo.Update` (Save всей модели) заменён на `UpdateMetadata`: обновляются только колонки настроек, условием по `id + updated_at`, сохранённая строка возвращается через `RETURNING`. Полного Save в контракте репозитория больше нет — это была ловушка: он писал ещё и `blocks` из снимка, прочитанного до правки. `Update` в usecase и хендлере читает ту же версию из `If-Match`, что и блоки, и отдаёт 409 с актуальным вишлистом. `ErrBlocksConflict` переименован в `ErrVersionConflict`.

На фронте временный safety gate удалён. `use-wishlist-draft.ts` сохраняет настройки и блоки двумя запросами строго по очереди: второй берёт версию, которую вернул первый. Заодно убраны сообщение «требуется обновление API» и кнопка «Отменить изменения настроек».

Тесты бэка: 4 интеграционных (блоки не затираются, возвращается свежая версия, устаревшая отвергается, без `If-Match` проверки нет) и 3 юнит-теста. Docker в окружении не поднят — интеграционные проверены только компиляцией под тегом `integration`.
