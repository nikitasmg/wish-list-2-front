## Блокеры API — сняты 29 сентября

Оба исправлены в бэкенде, коммит `4d9f8bb`.

1. CORS `AllowHeaders` теперь включает `If-Match` — браузер перестал резать заголовок на preflight.
2. `repo.Update` (Save всей модели) заменён на `UpdateMetadata`: обновляются только колонки настроек, условием по `id + updated_at`, сохранённая строка возвращается через `RETURNING`. Полного Save в контракте репозитория больше нет — это была ловушка: он писал ещё и `blocks` из снимка, прочитанного до правки. `Update` в usecase и хендлере читает ту же версию из `If-Match`, что и блоки, и отдаёт 409 с актуальным вишлистом. `ErrBlocksConflict` переименован в `ErrVersionConflict`.

На фронте временный safety gate удалён. `use-wishlist-draft.ts` сохраняет настройки и блоки двумя запросами строго по очереди: второй берёт версию, которую вернул первый. Заодно убраны сообщение «требуется обновление API» и кнопка «Отменить изменения настроек».

Тесты бэка: 4 интеграционных (блоки не затираются, возвращается свежая версия, устаревшая отвергается, без `If-Match` проверки нет) и 3 юнит-теста. Docker в окружении не поднят — интеграционные проверены только компиляцией под тегом `integration`.

## Решения, принятые по ходу

- **Ф9 (мобильные экраны) намеренно не сделан по макету.** План предполагал экран-заглушку «конструктор открывается на компьютере», но редактор уже сделан адаптивным: закрывать рабочую функциональность блокером — ухудшение. Создание с телефона идёт через `/templates`, страница адаптивная. Если нужен именно блокер из макета — это отдельное решение.
- **Ф4.2: «Enter дважды» заменён на Ctrl+Enter** — двойной Enter в contenteditable браузеры разбирают по-разному. Меню выбора типа по «/» не делалось.
- **Ф8.4: фото от гостей решено не делать.** Загрузка требовала бы публичного аплоада (`/upload` закрыт JWT, у гостя аккаунта нет), а это лимиты, модерация и злоупотребления. Текст поздравлений и показ уже готового фото работают.

## Ручная проверка адаптивного редактора

Редактор сделан адаптивным вместо заглушки «только на компьютере», автотестами на узкой ширине не покрыт. Что стоит посмотреть руками на ~390px (`pnpm dev`, DevTools → iPhone):

1. `/wishlist` — карточки в две колонки, поиск не вылезает за экран.
2. `/templates` — сетка шаблонов и правая колонка с телефоном становятся друг под другом, кнопка «Создать по шаблону» достижима.
3. `/wishlist/edit/<id>` — панель Блок/Страница/Доступ уходит под холст, а не жмёт его в полоску.
4. Правка текста на холсте: тулбар не уезжает за левый край, `Esc` закрывает, `Ctrl+Enter` добавляет блок следом.
5. Перетаскивание блоков пальцем и переключатель Десктоп/Телефон внутри холста.
6. Предпросмотр → переключатель ширины: страница гостя без горизонтальной прокрутки.
7. Статус сохранения («Сохраняем…» → «Сохранено») виден и не перекрывается.
