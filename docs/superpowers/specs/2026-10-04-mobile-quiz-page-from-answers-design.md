# Опросник v2: страница из ответов

Дата: 2026-10-04. Макет: канвас «Просто намекни — редизайн», секция «Опросник v2: страница из ответов» (`Quiz2*.dc.html`).

## Проблема

Создание с телефона по шаблону копирует в вишлист тексты-примеры: человек выбирает «ДР мужчины» и пишет, что праздник дома, а на странице остаются бар, настолки и стоп-лист, которого он не писал. Опросник v1 менял только название, имя, дату и место — остальная страница всё равно чужая.

## Решение

Шаблон отдаёт **оформление** (схема, шрифт, узор, вид обложки, раскладка рядов) и **набор блоков по умолчанию**. Содержимое блоков собирается **только из ответов**. Тексты-примеры в вишлист не попадают.

Касается только создания с телефона (опросник). Десктопный экран создания по шаблону не меняется — это отдельное решение.

## Шаги опросника

1. **Повод** — как в v1.
2. **Для кого** — имя (у свадьбы два), возраст — как в v1.
3. **Название** — как в v1.
4. **Когда** — дата и время, можно пропустить — как в v1.
5. **Что будет на странице** — чипы блоков в трёх группах. Отмечены блоки по умолчанию для повода. «Подарки» отмечены всегда.
6. **По экрану на каждый отмеченный блок с содержимым**, в фиксированном порядке. В шапке — «Заполню потом».
7. **Ваша страница** — превью из ответов и выбор оформления (шаблоны повода), «Создать вишлист».

«Где» перестаёт быть отдельным шагом — это блок «Место». У «Просто списка» шаги не меняются: повод → название.

### Каталог блоков

| Ключ | Название | Группа | Экран | Блок в вишлисте |
|---|---|---|---|---|
| `about` | Пара слов гостям | О празднике | текст + 3 готовые фразы под повод | подзаголовок обложки (`cover.data.subtitle`) |
| `place` | Место | О празднике | чипы «Дома / В кафе / На природе», место, адрес, как найти | `location` {name, address, note} |
| `program` | Программа | О празднике | строки «время + что», до 8 | `list` view `schedule`, items {t, v} |
| `dress` | Дресс-код | О празднике | до 5 цветов из 10 + подпись | `color_scheme` view `circles`, colors [{hex, name}], showNames, note |
| `contact` | Контакт | О празднике | имя, телеграм или телефон | `contact` {name, telegram \| phone} |
| `gifts` | Подарки | Про подарки | — (всегда) | `wishlist` |
| `likes` | Что люблю | Про подарки | чипы + своё, до 12 | `list` view `tags` |
| `stop` | Стоп-лист | Про подарки | чипы + своё, до 12 | `list` view `tags`, strike |
| `sizes` | Размеры | Про подарки | одежда, обувь, рост, кольцо | `list` view `tiles`, items {k, v}, только заполненные |
| `rsvp` | Ответ «Приду» | Для гостей | без вопросов | `rsvp` |
| `playlist` | Плейлист | Для гостей | без вопросов | `playlist` |
| `guestbook` | Поздравления | Для гостей | без вопросов | `guestbook` |

Порядок экранов: about, place, program, dress, contact, likes, stop, sizes.

### Блоки по умолчанию

- bday: about, place, stop, rsvp
- kids: about, place, likes, sizes, rsvp
- wedding: about, place, program, dress, contact, rsvp
- jubilee: about, place, rsvp, guestbook
- party: about, place, program, rsvp, playlist

(`gifts` — всегда.)

## API

`POST /wishlists/from-system-template` получает необязательный объект `page`. Без него — прежнее поведение (десктоп).

```json
{
  "template_id": "man", "title": "Дима, 35!", "name": "Дима", "age": 35,
  "event_date": "2026-11-14T16:00:00.000Z",
  "page": {
    "blocks": ["about", "place", "stop", "rsvp"],
    "about": "Без пафоса: друзья, еда и музыка.",
    "place": { "name": "Дома", "address": "ул. Садовая, 8", "note": "Домофон 12" },
    "program": [{ "t": "19:00", "v": "Собираемся" }],
    "dress": { "colors": [{ "hex": "#141414", "name": "Чёрный" }], "note": "" },
    "contact": { "name": "Оля", "way": "@olya" },
    "likes": ["настолки"], "stop": ["носки", "парфюм"],
    "sizes": { "clothes": "L · 50", "shoes": "43", "height": "", "ring": "" }
  }
}
```

Поля `place_name` / `place_address` из v1 убираются — место приходит в `page.place`.

Ограничения: строки до 200 символов (about — до 500), списки до 12, программа до 8, цветов до 5 и только `#RRGGBB`. Неизвестный ключ в `blocks` — 400.

## Сборка страницы на бэке (режим `page`)

1. Копия блоков шаблона с подставленным `{name}`.
2. Каждому блоку шаблона — ключ каталога: cover → обложка; wishlist → gifts; location → place; list schedule → program; list tags+strike → stop; list tags / pairs → likes; list tiles → sizes; color_scheme → dress; contact, rsvp, playlist, guestbook → одноимённые. Остальные блоки (цитата, фото, видео, голосование, история, текст) — примеры, удаляются.
3. Остаются обложка, gifts и блоки с ключом из `page.blocks` (по одному на ключ). Их позиция и вид — из шаблона, **data и заголовок заменяются** ответами и нейтральным заголовком ключа (у rsvp, playlist, guestbook data шаблона сохраняется — это настройки, а не факты).
4. Отмеченные ключи, которых в шаблоне нет, добавляются отдельными рядами: likes, stop, sizes — перед рядом подарков; остальные — в конец, в порядке каталога.
5. Раскладка уплотняется: пустые ряды убираются, номера рядов идут подряд, у ряда, где блоков стало меньше колонок, число колонок уменьшается, пропорция сбрасывается.
6. Отмеченный блок без содержимого создаётся **скрытым** (`hidden: true`) — гость его не видит, пока владелец не заполнит и не включит.
7. Обложка: заголовок — название, подзаголовок — `about` (пусто — без подзаголовка). У обложки «цифрой» цифра — возраст; без возраста вид меняется на `center`, чтобы не осталась цифра из примера.

Нейтральные заголовки: place «Где собираемся», program «Как пройдёт праздник», dress «Цвета праздника», contact «Остались вопросы?», likes «Если хочется угадать», stop «Пожалуйста, не дарите», sizes «Чтобы точно подошло», gifts «Подарки». Подписи (caption) — названия из каталога.

Контакт: `way`, начинающийся с `@` или `t.me/`, — телеграм, иначе телефон.

## Фронт

- `shared/create-quiz.ts` — каталог, блоки по умолчанию, шаги, подсказки-чипы и фразы, сборка `page` из ответов. Чистые функции, тесты в `tests/create-quiz.test.cjs`.
- `app/wishlist/create/components/create-quiz.tsx` — каркас опросника и базовые шаги; экраны блоков — в отдельном файле `quiz-block-steps.tsx`.
- Шаг «Ваша страница»: превью списком блоков с содержимым; незаполненные — пунктиром «скрыт»; ниже — шаблоны повода как варианты оформления.
