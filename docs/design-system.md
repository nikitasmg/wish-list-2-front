# Дизайн-система «Просто намекни»

Все размеры, скругления, тени и движения — **токены, названные по роли**.
Не пиксели: `text-label`, а не `text-[13px]`; `rounded-control`, а не
`rounded-[10px]`. Значения сведены из макета (канвас «Просто намекни —
редизайн») и кода; спека — `docs/superpowers/specs/2026-10-04-design-system-design.md`.

Где живут: `tailwind.config.ts` (ключи), `app/globals.css` (переменные
схем и ролей), `lib/utils.ts` (`cn` знает токены), `shared/motion.ts`
(пружины), `components/ui/` (компоненты).

## Типографика

Гарнитура — Manrope. Трекинг и интерлиньяж зашиты в токен, `tracking-*` и
`leading-*` рядом не нужны. Вес задают только заголовки; у текста —
классом `font-*` рядом (подписи полей и сегменты — `font-semibold`).

| Токен | px | Роль |
|---|---|---|
| `text-micro` | 11 | бейджи, «новый», «главная мечта» |
| `text-eyebrow` | 11, капс 0.08em, 700 | надпись над заголовком (добавить `uppercase`) |
| `text-caption` | 12 | шапки таблиц, подсказки, даты |
| `text-label` | 13 | подписи полей, сегменты, метаданные |
| `text-body-sm` | 14 | второстепенный текст, малые кнопки |
| `text-body` | 15 | основной текст, кнопки, поля |
| `text-lead` | 16 | подзаголовок под H1; поля ввода на телефоне |
| `text-body-lg` | 20 | крупный абзац: блок «Текст» размера «Крупный», цитата |
| `text-title-xs` | 17, 700 | заголовок в шапке, строки-карточки |
| `text-title-sm` | 20, 800 | заголовки блоков |
| `text-title` | 24, 800 | модалки, карточки вишлистов |
| `text-title-lg` | 32, 800 | H1 рабочих экранов |
| `text-display-sm` | 44, 800 | H1 кабинета |
| `text-display-md` | 56, 800 | заголовки секций лендинга |
| `text-display` | 64, 800 | крупные цифры и заголовки лендинга |
| `text-display-xl` | 112, 800 | герой лендинга |

Адаптивность — сменой токена: `text-title md:text-title-lg`.

## Скругления

Скругление растёт с размером элемента.

| Токен | px | Роль |
|---|---|---|
| `rounded-xs` | 4 | образцы цвета, мелкие метки |
| `rounded-tag` | 8 | бейджи, кнопки ≤ 30px, сегмент в переключателе, превью 34–48px |
| `rounded-control` | 10 | кнопки и поля 32–40px |
| `rounded-control-lg` | 14 | кнопки и поля 44–56px, меню, поповеры |
| `rounded-card` | 18 | карточки, панели |
| `rounded-sheet` | 24 | модалки, шторки, макет телефона |
| `rounded-full` | — | аватары, точки, таблетки |
| `rounded-block` | `--radius` схемы | блоки страницы гостя |
| `rounded-block-sm` | `--radius` − 4 | фото и кнопки внутри блока гостя |

**Вложенность:** внутренний радиус = внешний − отступ. Переключатель:
контейнер `rounded-control` + `p-0.5` → сегменты `rounded-tag`.

## Отступы

Шкала Tailwind (4px). Разрешено: `0 px 0.5 1 1.5 2 2.5 3 3.5 4 5 6 7 8 9 10
12 14 16 18 20`, на лендинге ещё `24 28 32`. Произвольные `p-[…]` — нет.

Близость: внутри группы меньше, чем между группами.

| Уровень | `gap` |
|---|---|
| иконка + текст в элементе | `2` |
| поля формы, пункты списка | `3`–`3.5` |
| группы на экране | `5`–`6` |
| секции | `9`–`14` |
| поля страницы | `px-4 md:px-16` |

## Высоты элементов управления

| Токен | px | Где |
|---|---|---|
| `h-control-sm` | 32 | сегменты, малые кнопки, тулбары |
| `h-control` | 40 | обычные кнопки |
| `h-control-lg` | 48 | поля форм, главные кнопки, всё основное на телефоне |
| `h-control-xl` | 56 | крупные CTA |

Квадратные кнопки-иконки — `size-control`, `size-control-sm`… Метки-кнопки
внутри карточек гостя («Беру») — `h-7` + `rounded-block-sm`.

## Тени

| Токен | Роль |
|---|---|
| `shadow-float` | тосты, меню, поповеры, перетаскиваемый блок |
| `shadow-overlay` | модалки, шторки, макеты устройств |
| `shadow-ring` | выбранный элемент (не фокус) |
| `shadow-drop` | место вставки при перетаскивании (линия сверху) |

У кнопок, полей и карточек теней нет. Сила тени зависит от темы
(`--shadow-alpha`).

## Цвета

Семь ролей схемы (`background`, `card`, `border`, `foreground`,
`muted-foreground`, `primary`, `accent`) плюс `success`, `warning`,
`destructive`, `overlay` (подложка модалок), `bg-brand` (градиент главной
кнопки интерфейса, один для обеих тем), `bg-hero-night` + `bg-dots` (шапки объявлений).

Hex и `rgba()` в TSX — только в файлах-данных (палитры схем, дресс-код,
конфетти, базы «своей схемы» — `CUSTOM_BASES`). Мокапы схем рисуются классами схем (`.midnight`, `.linen`) и
ролями.

## Лендинг и иллюстрации

- Палитра бренда, одна в обеих темах: `brand-cyan`, `brand-sky`, `brand-violet`,
  `brand-ink`, `brand-night`, `brand-chat`. Только для лендинга и иллюстраций —
  интерфейс красится ролями схемы.
- Тона иконок и плашек: `tone-cyan`, `tone-violet`, `tone-pink` — на светлом
  темнее, на тёмном светлее (`bg-tone-pink/15 text-tone-pink`).
- Фоны: `bg-glow-cyan`, `bg-glow-violet` (свечения), `bg-hero-night` + `bg-dots`.
- **Превью-картинки помечаются.** Мокап, нарисованный живыми блоками, —
  класс `EXAMPLE` (не ловит указатель, не выделяется) и метка
  `<ExampleBadge>` («Пример») в углу. Иначе кнопки в нём хочется нажать.
  Настоящие интерактивные демо (выбор схемы) метку не получают.

## Движение

| Токен | Значение | Роль |
|---|---|---|
| `duration-fast` | 120ms | нажатие, наведение |
| `duration-base` | 200ms | меню, смена состояния, тост |
| `duration-slow` | 320ms | модалка, шторка |
| `ease-out-soft` | `cubic-bezier(.22,1,.36,1)` | появление |

`spring.default` (без отскока) и `spring.sheet` (лёгкий отскок, только
после жеста) — из `@/shared/motion`. Анимировать только `transform` и
`opacity`. При `prefers-reduced-motion` остаётся только прозрачность — это
делает `globals.css`.

## Компоненты

- `Button` — `variant`: `default` (цвет схемы), `brand` (градиент, главное
  действие интерфейса), `secondary`, `outline`, `ghost`, `destructive`,
  `link`; `size`: `sm`, `default`, `lg`, `xl`, `icon-sm`, `icon`, `icon-lg`.
  Нажатие сжимает до 0.97.
- `Input`, `Textarea` — 48px, 16px текста до `md` (иначе iOS увеличивает
  страницу при фокусе). В плотных панелях (инспектор конструктора) —
  обёртка `<InputDensity value="md">`: поля 40px, как в макете.
- `Segmented`, `Switch`/`Toggle`, `Field`, `ViewTiles`, `Badge`, `Card`,
  `Dialog`, `Sheet`, `Popover`, `DropdownMenu`, `Toast`.
- Фокус у всего интерактивного: `focus-visible:ring-2 ring-ring
  ring-offset-2 ring-offset-background`.
- Сырой `<button>` — только там, где это не кнопка по виду: ячейки холста,
  ручки, кружки цвета, плитки. Классы и там — токены.

## Так / не так

| Не так | Так | Почему |
|---|---|---|
| `text-[13px] tracking-[-0.02em]` | `text-label` | трекинг уже в токене |
| `rounded-[11px]` | `rounded-control` | одно значение на роль |
| `shadow-sm` у кнопки | без тени | в макете у элементов управления теней нет |
| `transition-all duration-300` | `transition-[transform,opacity] duration-base` | анимируем только то, что двигается |
| появление из `scale(0)` | `scale(.96)` + прозрачность | ничто в мире не появляется из точки |
| `style={{ color: '#FFD166' }}` | `text-warning` | цвет — роль, а не hex |
| `<button className="h-10 rounded-xl bg-primary …">` | `<Button>` | один компонент — одно поведение |
